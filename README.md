# The Blind Tiger - Cajun & Creole Saloon

A high-fidelity, responsive restaurant website built for **The Blind Tiger**, a historic Cajun/Creole eatery in downtown Shreveport, Louisiana (Est. 1992).

## 🚀 Overview

This project was developed as a modern, performance-oriented prototype to showcase the restaurant's unique "Saloon Modern" aesthetic. It features a sophisticated dark theme with gold accents, smooth animations, and a functional multi-step online ordering system.

## 🛠 Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Routing:** React Router DOM v6
- **Icons:** Lucide React
- **Deployment:** Vercel

## ✨ Key Features

- **Dynamic Hero Section:** Staggered load animations and brand-focused imagery.
- **Tabbed Menu System:** Categorized menu with persistent URL hashing for easy sharing.
- **Multi-Step Order Form:** A functional 4-step ordering process (Selection → Details → Review → Confirmation).
- **SEO Optimized:** Includes Meta Tags, Open Graph cards, and JSON-LD Structured Data for Local Business.
- **Responsive Design:** Custom-tailored experience across mobile, tablet, and desktop.
- **Branding:** Integrated official "The Blind Tiger" logo and custom-generated SVG favicons.

## 📦 Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/Robin239105/The-Blind-Tiger.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
4.  Build for production:
    ```bash
    npm run build
    ```
